## 1. Создать новую сессию

```bash
screen -S mybot
```

## 2. Запустить бота внутри сессии

```bash
cd TgBot
python3 bot.py
```

## 3. Отсоединиться от сессии

Нажми клавиши: Ctrl + A, затем D.

## 4. Вернуться к работающему боту

```bash
screen -r mybot
```

## 5. Посмотреть список всех сессий

```bash
screen -ls
```

## 6. Полностью закрыть сессию

```bash
exit
```
