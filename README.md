# TgBot — Telegram бот для відстеження цін та сповіщень

Простий Telegram-бот, який автоматично відстежує ціни на товари й надсилає сповіщення, коли ціна змінюється або падає до заданого рівня.

## Що вміє проєкт

-  Додавати товар до треку за URL через команду /add_track <url> [target_price]
-  Зберігати поточну ціну та бажану цільову ціну у локальній базі SQLite
-  Періодично перевіряти сторінки товарів та оновлювати поточну ціну
-  Надсилати сповіщення користувачу, коли ціна змінилася
-  Окремо повідомляти, коли ціна стала нижчою або рівною цільовій
-  Переглядати список активних треків командою /my_tracks
-  Видаляти треки за допомогою кнопки у повідомленні

## Як працює трекер цін

1. Користувач надсилає /add_track <url> [target_price]
2. Бот парсить сторінку товару й намагається отримати назву та ціну
3. Трек зберігається в таблиці tracked_products
4. Планова задача за розкладом перевіряє всі збережені товари
5. Якщо ціна змінилася, бот надсилає повідомлення
6. Якщо нова ціна нижча або рівна цільовій, бот надсилає спеціальне повідомлення

## Основні команди

- /start - привітання та опис можливостей
- /add_track <url> [target_price] - додати новий товар для відстеження
- /my_tracks - показати всі поточні треки
- /roll - випадкове число
- /meowfact - цікавий факт про котів
- /play_ttt - запустити гру хрестики-нулики
- /help - виводить усі команди

## Технології

- Python
- Telegram Bot API через aiogram
- HTTP-запити через aiohttp
- HTML-парсинг через BeautifulSoup
- База даних SQLite
- Планова перевірка цін за розкладом

## Налаштування

- Інтервал перевірки задається змінною оточення PRICE_CHECK_INTERVAL_HOURS
- Також можна використовувати PRICE_CHECK_INTERVAL_MINUTES або PRICE_CHECK_INTERVAL_SECONDS
- Бот обробляє URL-адреси http:// та https://
- Підтримує різні формати ціни на сторінці, включно з метатегами та текстовими селекторами

## Запуск локально

1. Встановити залежності: pip install -r requirements.txt
2. Створити файл .env з BOT_TOKEN і за потреби GEMINI_API_KEY
3. Запустити бота: python bot.py

## Запуск на AWS

Якщо ви розгортаєте бота на AWS (наприклад, на EC2), використайте послідовність, яка вже працює для вас:

1. Підключитися до сервера через SSH.
2. Перейти до директорії проєкту: cd /path/to/TgBot.
3. Оновити код з репозиторію: git pull origin main.
4. Активувати віртуальне оточення: source .venv/bin/activate.
5. Встановити оновлені залежності: pip install -r requirements.txt.
6. Перезапустити службу бота: sudo systemctl restart tgbot.
